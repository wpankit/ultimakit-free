# Getting help

- **Setting up or using the plugin:** ask on the [WordPress.org support forum](https://wordpress.org/support/plugin/ultimakit-for-wp/).
- **A bug or an idea:** open an [issue](https://github.com/wpankit/ultimakit-for-wp/issues/new/choose).
- **A security issue:** follow the [security policy](SECURITY.md) and report it privately.
